SQL vs NoSQL

* SQL databases store data mainly in tables made up of rows and columns.
* Examples: MySQL, PostgreSQL, Oracle, SQL Server.
* SQL is suitable when data has a fixed structure, strong relationships, complex joins, and transactions are important.
* NoSQL databases use flexible data models instead of the traditional table-and-row structure.
* MongoDB is a NoSQL database that stores data as documents.
* MongoDB is useful when data structures can change frequently, data is naturally represented as nested objects, or horizontal scalability is important.
* Example: A product catalog where laptops can have RAM and storage fields while shirts can have size and color fields.
* Neither SQL nor NoSQL is universally better; the choice depends on the application's requirements.

Documents and Collections

* A **document** is similar to a row/record in SQL.

* A document stores data as key-value pairs.

* Example:
  {
    "name": "Rahul",
    "age": 22,
    "city": "Pune"
  }

* A **collection** is a group of related documents.

* A collection is roughly similar to a table in SQL.

* Example:
  users
  { "name": "Rahul", "age": 22 }
  { "name": "Priya", "age": 24 }
  { "name": "Aman", "age": 21 }

* MongoDB hierarchy:
  Database → Collection → Document

JSON and BSON

* JSON stands for JavaScript Object Notation.
* MongoDB documents look similar to JSON, making them easy for developers to understand.
* BSON stands for Binary JSON.
* MongoDB internally stores documents using BSON.
* BSON supports additional data types such as Date and ObjectId.
* Simple way to remember:
  JSON → easy-to-read representation
  BSON → format MongoDB uses internally to store documents

MongoDB Atlas

* MongoDB Atlas is MongoDB's cloud-based database service.
* It allows you to create and use MongoDB databases without installing the database server locally.
* Atlas provides a free tier suitable for learning and small practice projects, subject to current limits.
* Basic setup:

  1. Create/sign in to a MongoDB Atlas account.
  2. Create a project.
  3. Create a database deployment/cluster.
  4. Create a database user.
  5. Configure Network Access and add your IP address.
  6. Use the connection string to connect to the database.
* Never share your database password or real connection string publicly.

MongoDB Compass

* MongoDB Compass is a GUI (Graphical User Interface) for MongoDB.
* It allows you to create databases and collections, insert, view, edit, and delete documents, and run queries using a graphical interface.
* Compass can connect to MongoDB Atlas using the connection string provided by Atlas.

Connect Atlas with Compass

1. Open MongoDB Atlas.
2. Open your database deployment.
3. Click Connect.
4. Select MongoDB Compass.
5. Copy the connection string.
6. Replace `<username>` and `<password>` with your database credentials if required.
7. Open MongoDB Compass.
8. Paste the connection string.
9. Click Connect.
10. After connecting, Compass will display the databases available in Atlas.

Example connection string:
mongodb+srv://<username>:<password>@<cluster-url>/

* If the connection fails, check the username, password, Network Access/IP rule, and connection string.
* Never commit a real connection string containing credentials to GitHub.

MongoDB Shell CRUD Commands

1. Create / Select Database

    use training_db

    MongoDB creates the database when you first insert data into it.

2. Create Collection

    db.createCollection("students")

3. CREATE — Insert Documents

    Insert one document:

    db.students.insertOne({
        name: "Rahul",
        age: 21,
        city: "Pune",
        course: "Backend"
    })

    Insert multiple documents:

    db.students.insertMany([
        {
            name: "Priya",
            age: 23,
            city: "Mumbai",
            course: "Data Science"
        },
        {
            name: "Aman",
            age: 22,
            city: "Delhi",
            course: "Backend"
        },
        {
            name: "Sneha",
            age: 20,
            city: "Pune",
            course: "Frontend"
        }
    ])

4. READ — Retrieve Documents

    Retrieve all documents:

        db.students.find()

    Retrieve one document:

        db.students.findOne({ name: "Rahul" })

    Find students from Pune:

        db.students.find({ city: "Pune" })

    Find students older than 21:

        db.students.find({
            age: { $gt: 21 }
        })

    Find students from Pune or Mumbai:

        db.students.find({
            city: { $in: ["Pune", "Mumbai"] }
        })

    Find students older than 22 OR from Pune:

        db.students.find({
            $or: [
                { age: { $gt: 22 } },
                { city: "Pune" }
            ]
        })

    Sort by age in ascending order:

        db.students.find().sort({ age: 1 })

    Sort by age in descending order:

        db.students.find().sort({ age: -1 })

    Get the first two documents:

        db.students.find().limit(2)

    Count all students:

        db.students.countDocuments()

    Count students from Pune:

        db.students.countDocuments({
            city: "Pune"
        })

5. UPDATE — Modify Documents

    Update Rahul's age:

        db.students.updateOne(
            { name: "Rahul" },
            { $set: { age: 22 } }
        )

    Update all Backend students' city:

        db.students.updateMany(
            { course: "Backend" },
            { $set: { city: "Bangalore" } }
        )

Increase Sneha's age by 1:

        db.students.updateOne(
            { name: "Sneha" },
            { $inc: { age: 1 } }
        )

    Add a new field:

        db.students.updateOne(
            { name: "Priya" },
            { $set: { fees: 50000 } }
        )

    Remove a field:

        db.students.updateOne(
            { name: "Priya" },
            { $unset: { fees: "" } }
        )

6. DELETE — Remove Documents

    Delete one document:

        db.students.deleteOne({
            name: "Sneha"
        })

    Delete multiple documents:

        db.students.deleteMany({
            city: "Pune"
        })

    Delete all documents:

        db.students.deleteMany(
{})

WARNING: `deleteMany({})` deletes every document in the collection. The collection itself still exists.

Shell vs Compass

* MongoDB Shell is useful for learning and directly executing MongoDB commands.
* Compass is useful for visually exploring and managing MongoDB data.
* Both interact with the same MongoDB database.
* Learning shell commands is useful even when using Compass because applications eventually perform database operations programmatically.

GitHub Safety

* Never upload MongoDB passwords or real connection strings to GitHub.
* Add `.env` and other files containing secrets to `.gitignore`.
* Use placeholders in notes:
  mongodb+srv://<username>:<password>@<cluster-url>/
* If credentials are accidentally pushed to GitHub, change or revoke them immediately.
